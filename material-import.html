Hardware definitions

The hardware types Creative can add to a job, and the suggested values for each. Options are suggestions, never a closed list — a one-off can always be typed in, same rule as materials.

Browse the reference data

Everything Creative can pick — materials and hardware together. Hardware is listed one row per combination, because a type with option lists isn’t one choice, it’s many. Inactive rows (dimmed) are hidden from the picker but kept for existing jobs. This tab is read-only; the two edit tabs change the data.

Connecting…

Production departments

One bucket per shop. Put a decoration or a material category in a bucket and any job using it pulls that department in. BLC makes people toggle departments by hand — this is what replaces that. What a department does to the tier lives in Escalation, not here.

Tier escalation

One bucket per tier, holding everything that pushes a job into it, plus the lead time that tier carries. Rules only ever raise the tier — a job lands on the highest one anything triggers.
